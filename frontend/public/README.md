# Public Assets

Place your logo file here.

## Logo Requirements

- **File name**: `logo.png` or `logo.svg` (recommended: SVG for scalability)
- **Recommended size**: 
  - For Navbar: 32x32px to 48x48px
  - For Sidebar: 24x24px to 32x32px
  - For Welcome Screen: 80x80px to 120x120px
- **Format**: PNG (with transparency) or SVG
- **Background**: Transparent preferred

## File Structure

```
public/
  ├── logo.png (or logo.svg)
  └── README.md
```

## Usage

The logo will be used in:
1. **Navbar** - Top navigation bar
2. **Sidebar Footer** - Bottom of the sidebar
3. **Welcome Screen** - Main landing area
